# 渠道与配置

识别、翻译与配音分别由 `videotrans.recognition`、`videotrans.translator`、`videotrans.tts` 的包级注册表管理。每类渠道通过统一 `run()` 入口按整数渠道 ID 延迟加载实现类。

## 注册约束

- 注册表保存 ID、显示名称、实现模块、可选凭据键和设置窗口。
- 渠道 ID 会被 GUI、CLI 与持久化配置使用；新增时只追加，不重排和复用。
- 需要 API 凭据或地址的渠道应使用现有配置系统和凭据检查；不得把密钥写入日志、文档样例或测试。

## 配置与状态

`AppSettings` 管理全局运行设置，`AppParams` 管理用户选择和渠道参数，`AppCfg` 保存进程内状态。配置文件可能含密钥，运行和部署规则见 [[运维/部署与入口]]。

## 扩展入口

新增渠道通常需要：实现对应 `BaseRecogn`、`BaseTrans` 或 `BaseTTS` 子类；注册渠道；补齐必要的参数和设置窗口；为语言或音色增加映射；添加不依赖网络和模型下载的测试。
