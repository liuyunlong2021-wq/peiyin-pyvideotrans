# 任务流水线

`TransCreate` 负责完整视频翻译任务；`SpeechToText`、`TranslateSrt` 与 `DubbingSrt` 分别承载单项转录、字幕翻译和字幕配音。任务配置由 `TaskCfgBase` 派生出的 STT、TTS、STS、VTT dataclass 传递。

## 阶段与分流

完整任务依次经过预处理、识别、可选说话人分离、翻译、可选配音、对齐、可选二次识别、合成和收尾。`should_recogn`、`should_trans`、`should_dubbing`、`should_hebing`、`should_separate` 决定哪些阶段参与。

批量任务由队列 Worker 编排；单任务可复用相同阶段实现。停止由全局退出状态和任务 UUID 停止集合协同处理。

## 维护边界

- 新增任务输入字段放入 `task/taskcfg.py` 的相应 dataclass，避免在入口和界面之间维护并行字典。
- SRT 在任务层以 `SrtItem` 传递，保留行号、时间戳、说话人和文件名字段。
- 音频时长变化的规则见 [[架构/音画对齐]]；渠道调用和运行时配置见 [[架构/渠道与配置]]。
