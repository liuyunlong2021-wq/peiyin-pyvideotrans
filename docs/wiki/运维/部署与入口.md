# 部署与入口

源码运行要求 Python 3.10、FFmpeg 和 `uv`。常用入口为：桌面 GUI 的 `sp.py`、无界面任务的 `cli.py`，以及可选 WebUI 的 `webui.py`。

## 剧情翻译与声音克隆

韭菜盒子剧情翻译工作流在桌面 GUI 中使用：先识别/校对中文字幕，再用设置页选定的云端模型按整集上下文翻译，随后在英文校对窗口人工确认“接上句”，最后由本地 Qwen3-TTS 按完整发言轮次克隆。字幕仍逐句保留，人工分组写入任务目录的 `turns.json`。

该流程需要在本机配置韭菜盒子 API URL/Key（翻译和人物建议）以及本地 Qwen3-TTS 模型。API Key 只保存在本地配置，不应提交到 Git 或写入 Wiki。

## 常用命令

```bash
uv sync
uv run sp.py
uv run cli.py --help
uv sync --extra webui
uv run webui.py
```

CLI 提供 `stt`、`tts`、`sts`、`vtv` 四类任务。以 `--list providers`、`--list languages` 和 `--list models` 获取运行时可用项，避免在脚本中固化渠道编号或模型清单。

## 运行数据

模型、日志、临时文件和输出目录均由项目配置与运行路径决定。`params.json`、`cfg.json` 可能含 API 凭据，部署时需作为敏感配置处理。完整任务的流程见 [[架构/任务流水线]]；浏览器部署见 [[运维/WebUI]]；AMD 场景可参考 [[运维/Whisper.NET]]。
