# 部署与入口

> 当前产品：赚钱音浪 1.0.0；Bundle ID：`studio.jiucaihezi.zhuanqianyinlang`

源码运行要求 Python 3.10、FFmpeg 和 `uv`。常用入口为：桌面 GUI 的 `sp.py`、无界面任务的 `cli.py`，以及可选 WebUI 的 `webui.py`。

## 剧情翻译与声音克隆

韭菜盒子剧情翻译工作流在桌面 GUI 中使用：先识别/校对中文字幕，再用设置页选定的云端模型按整集上下文翻译，随后在英文校对窗口人工确认“接上句”，最后由本地 Qwen3-TTS 按完整发言轮次克隆。字幕仍逐句保留，人工分组写入任务目录的 `turns.json`。

该流程需要在本机配置韭菜盒子 API URL/Key（翻译和人物建议）以及本地 Qwen3-TTS 模型。API Key 只保存在本地配置，不应提交到 Git 或写入 Wiki。

## 常用命令

```bash
uv sync
uv run sp.py
uv run cli.py --help
uv sync --extra webui
uv run webui.py
```

## macOS 双击启动

完成 `uv sync` 后，保留 `赚钱音浪.app` 在仓库根目录并双击，或执行：

```bash
open "赚钱音浪.app"
```

`.app` 不是大型安装包，只包含品牌图标、`Info.plist` 和约 49 KB 的通用原生启动器。启动器同时支持 Apple Silicon 与 Intel Mac，运行时动态读取当前仓库 `.venv` 中的 Python 3.10，再执行 `sp.py`；模型、依赖和业务代码不复制进 `.app`。缺少 `.venv` 时会提示先执行 `uv sync`。

原生启动器必须保留，因为 shell `exec python` 会让 macOS Dock 把应用登记为 `python3.10`。当前实现已由系统进程注册表验证为名称“赚钱音浪”、版本 `1.0.0` 和上述 Bundle ID。

当前最小启动壳未做 Apple 开发者签名。GitHub 下载文件若被 Gatekeeper 拦截，首次使用右键“打开”并再次确认；不为解决该提示引入 DMG、公证或完整应用打包。

CLI 提供 `stt`、`tts`、`sts`、`vtv` 四类任务。以 `--list providers`、`--list languages` 和 `--list models` 获取运行时可用项，避免在脚本中固化渠道编号或模型清单。

## 运行数据

模型、日志、临时文件和输出目录均由项目配置与运行路径决定。`params.json`、`cfg.json` 可能含 API 凭据，部署时需作为敏感配置处理。完整任务的流程见 [[架构/任务流水线]]；浏览器部署见 [[运维/WebUI]]；AMD 场景可参考 [[运维/Whisper.NET]]。

## 验证边界

已在 macOS Apple Silicon 上完成 `uv` 环境、桌面 GUI、品牌启动器、真实短样片完整流程和本地 Qwen3-TTS 1.7B 验证。通用启动器包含 x86_64 架构，但 Intel Mac、Windows、Linux、Docker、CUDA 与首次模型下载仍需在对应目标环境验收。发布检查见 [[巡检报告/赚钱音浪1.0.0发布一致性检查]]。
