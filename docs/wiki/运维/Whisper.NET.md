# Whisper.NET

Whisper.NET 是面向 Windows/AMD 等场景的可选识别渠道，需要额外的 .NET 本机库和模型文件。安装前应按原始指南核对 DLL、模型文件、目录结构与 Vulkan/GPU 兼容性。

## 排查顺序

1. 确认所需本机库与模型已放在文档要求的位置。
2. 出现 `Native Library not found` 或 `0x8007007E` 时先检查 DLL 完整性和位数匹配。
3. GPU 不生效时检查 Vulkan 支持、驱动和渠道配置。
4. `pythonnet` 初始化失败时按原始安装指南核对运行环境。

该渠道为可选依赖；安装和平台兼容性未在本轮验证。通用环境入口见 [[运维/部署与入口]]，具体错误归类见 [[排障/常见问题]]。
