# Google Cloud TTS

Google Cloud Text-to-Speech 是一个可选 TTS 服务集成，支持多语言音色、语速、音调和多种音频格式。使用前需满足原始指南中的 Google Cloud 项目、认证凭据和 Python 依赖要求。

## 运维边界

- 凭据应通过安全配置提供，不提交到仓库、不写入日志或 Wiki。
- 音色、语言和配额以 Google Cloud 当前账户与服务端状态为准。
- 认证失败、权限不足或配额问题先检查服务启用状态、凭据路径与项目权限。

渠道注册和配置约束见 [[架构/渠道与配置]]；通用 TTS 故障入口见 [[排障/常见问题]]。
