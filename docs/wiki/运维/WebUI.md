# WebUI

WebUI 是可选的 Gradio 界面，适用于远程访问、局域网服务和容器化部署。安装额外依赖后以 `uv run webui.py` 启动；默认文档示例使用 7860 端口。

## 运维要点

- Docker 部署需要挂载输出目录与 `videotrans/` 配置目录，才能保留结果和参数。
- GPU 容器需要宿主机具备相应 NVIDIA 容器运行环境，再使用 `--gpus all`。
- WebUI 复用桌面端参数文件；API 渠道的地址和密钥应先正确配置，并按敏感信息处理。
- 文档说明 WebUI 是功能子集，实时字幕编辑和批量处理仍应使用桌面端。

运行入口、配置和未验证平台边界见 [[运维/部署与入口]]；渠道选择机制见 [[架构/渠道与配置]]。
