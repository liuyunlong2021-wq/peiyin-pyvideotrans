# 赚钱音浪 1.0.0 发布一致性检查

> 日期：2026-07-31
> 范围：品牌、源码部署、macOS 启动、Wiki、README、自动测试与敏感信息边界

## 发布结论

赚钱音浪 1.0.0 采用源码部署：用户克隆本仓库并执行 `uv sync`。macOS 用户随后双击仓库根目录的 `赚钱音浪.app`；Linux、Windows 或备用方式执行 `uv run sp.py`。不发布包含 Python、模型和依赖的大型独立安装包。

## 一致性基线

| 项目 | 当前真源 | 期望值 |
|---|---|---|
| 产品名称与版本 | `videotrans/__init__.py` | 赚钱音浪 / 1.0.0 |
| Bundle ID | `videotrans/__init__.py`、`.app/Contents/Info.plist` | `studio.jiucaihezi.zhuanqianyinlang` |
| 窗口与启动图 | `sp.py`、`videotrans/mainwin/main_win.py`、`videotrans/styles/` | 名称、版本和金钟声波图标一致 |
| macOS Dock 身份 | `.app/Contents/MacOS/launch` | 原生通用 Mach-O，不显示 `python3.10` |
| 安装入口 | `README.md`、`docs/README_CN.md`、[[运维/部署与入口]] | 当前仓库地址、`uv sync`、双击 `.app` 或 `uv run sp.py` |
| 上游版本 | `VERSION`、`pyproject.toml` | 仅用于 pyVideoTrans 兼容，不作为产品显示版本 |

## 已验证证据

- `赚钱音浪.app` 的 `Info.plist` 通过 `plutil -lint`；启动器同时包含 arm64 与 x86_64 架构。
- macOS `lsappinfo` 返回名称“赚钱音浪”、版本 `1.0.0`、正确 Bundle ID 和 `.app` 路径。
- 应用实际加载仓库 `.venv`、PySide6 与 `sp.py`，没有复制 Python、模型或业务依赖。
- 真实短样片完整跑通 SenseVoice、剧情翻译、本地 Qwen3-TTS 1.7B、音画对齐和最终合成；项目模式继续保持实验入口，原完整流程未被替换。
- 全库自动测试 490 项通过。原 `test_stt_fun_split.py` 中 25 项旧入口测试已删除，保留并迁移为当前识别模块导入、SenseVoice 标签、文本清洗、断句和日志测试。
- API Key 只保存在被 `.gitignore` 排除的 `videotrans/params.json` / `videotrans/cfg.json`，README 和 Wiki 不记录真实密钥。

## 保留边界

- x86_64 启动器已构建但尚未在 Intel Mac 真机运行。
- macOS 启动壳未做 Apple 开发者签名与公证，GitHub 下载后的首次启动可能需要右键“打开”。
- Windows、Linux、Docker、CUDA 和新机器首次模型下载尚未做本轮发布验收。
- 真实整集角色参考库 A/B 仍是后续质量验证，不阻塞 1.0.0 当前完整流程发布。
