# 语言包与扩展

语言资源在 `videotrans/language/` 中维护。新增或修订语言时，需要同步处理界面显示、翻译渠道映射和语言代码列表，而不是只修改一份展示文案。

## 修改原则

- 将用户可见文本接入现有翻译资源和 `config.tr()`，共享流程避免单语硬编码。
- 对照 `translate_language`、`ui_lang`、`toolbox_lang` 与 `language_code_list` 的现有结构补齐新增语言。
- 通道的语言可用性与音色/模型映射是独立约束，修改后应检查相关渠道的支持范围。

渠道级扩展的注册、配置和测试要求见 [[架构/渠道与配置]]。文档只记录维护规则；具体语言列表以运行时注册和语言 JSON 为准。
