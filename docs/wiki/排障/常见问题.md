# 常见问题

用户文档将问题集中为安装启动、识别、翻译、配音、声音克隆、FFmpeg 合成、GPU、批处理、路径和 CLI 等类别。排障先记录实际错误、平台、渠道、模型、输入媒体和日志，再按下面的边界缩小范围。

## 高优先级路径

- 启动或 FFmpeg 报错：核对 Python 3.10、FFmpeg 可执行文件、PATH、依赖安装和输入路径。
- 识别为空或显存不足：核对源语言、有效人声、模型大小、计算精度、GPU 可用内存和降噪选项。
- 翻译行错位或旧结果：检查整段字幕发送、并发设置和翻译缓存；确认是否清理了旧产物。
- 配音失败或静音：检查渠道限流、代理、本地 TTS 服务地址和凭据；不要在日志中暴露密钥。
- 音画不同步：检查音频加速、视频慢速、配音语速和二次识别；原理和限制见 [[架构/音画对齐]]。

## 证据要求

文档给出的是建议，不等同于已定位根因。每个新故障应在此目录建立独立记录，包含复现条件、根因、修复、回归命令和未验证平台，并关联 [[架构/任务流水线]] 或相应运维页。
