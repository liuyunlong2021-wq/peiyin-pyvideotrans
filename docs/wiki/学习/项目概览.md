# 项目概览

赚钱音浪 1.0.0 是基于 pyVideoTrans 的本地短剧翻译与声音克隆工作台。主链路为 ASR、整集上下文翻译、人工中英文与发言轮次校对、本地 Qwen3-TTS 克隆、字幕处理和最终媒体合成，并保留 GUI、CLI 与可选 WebUI 三种入口。

项目既支持本地模型和服务，也支持外部 API；不同渠道的可用性、模型和凭据要求以运行时注册与当前配置为准。`赚钱音浪 1.0.0` 是产品版本，代码中保留的 pyVideoTrans `VERSION`/包版本用于上游兼容与更新判断，不应显示为产品品牌版本。功能实现见 [[架构/任务流水线]]，部署与发布见 [[运维/部署与入口]]。

本页不替代发布说明、授权声明或捐助名单；这些内容仍保留在原始文档。
